# site-generator-speed-01-run-20261122

A fast drop-in for make.fun's own makefun-site 1.0.0: `run(input)` returns the
same static-site output tree, byte for byte, in clearly less CPU time. The
Markdown renderer works in one pass straight into the output, inline markup
is scanned in slices, slugs are memoised inside a case, and templates render
into a shared output list. Nothing is cached from one case to the next.
